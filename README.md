# react-native-app-guard

Native root/jailbreak, screen-recording, and screenshot detection for React Native — built with TurboModules for fintech-grade security.

## Installation


```sh
npm install react-native-app-guard
```


## Usage


```js
import { multiply } from 'react-native-app-guard';

// ...

const result = multiply(3, 7);
```
